## ADDED Requirements

### Requirement: Configured multi-client execution
Client packages SHALL declare immutable scoped processes, evidence policies and memory boundaries and execute through existing case and runtime services.

#### Scenario: Retail fixture
- **WHEN** a configured retail complaint package is installed
- **THEN** its distinct stages, evidence and capabilities execute without client-specific engine branches

### Requirement: Provenance-backed advisory learning
Feedback SHALL distinguish verified execution, source observations, human reports, inferred conclusions and synthetic assumptions. Experience SHALL NOT grant authority.

#### Scenario: Historical ranking
- **WHEN** compatible verified execution records exist
- **THEN** deterministic ranks may guide current validated capability and tool selection without bypassing Registry checks

### Requirement: Reviewed late-evidence reassessment
The backend SHALL archive original state and re-execute only affected analytical dependencies within existing approval and budget constraints.

#### Scenario: Late actual event
- **WHEN** an authorized operator binds a saved correlated event to affected inputs
- **THEN** original conclusions and unrelated completed work remain inspectable and uncertain writes are never replayed
