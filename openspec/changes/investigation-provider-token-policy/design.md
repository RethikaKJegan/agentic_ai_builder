# Design

Server-owned model-factory token policy defaults to bounded; investigations explicitly opt into provider-managed tokens. In provider mode no application token ceiling/cost reservation is enforced and max_output_tokens is omitted, while actual nonnegative usage is recorded and call/time limits remain. Shared contract shapes and default enforcement remain unchanged. Legacy finite budget values in the generic agent template are superseded only by this explicit server-owned investigation policy; expose the effective policy in capabilities, analysis outputs and reports.

Retain full existing source context and strict citations. A final-summary provider truncation returns a backend evidence compilation, with usage/reason, no invented findings and a visible report qualification. Other failures and prerequisite-agent failures remain errors. Preserve old failed run; test a fresh run without silently replaying paid calls.
