# Generate workflows without follow-up questions

The user explicitly requests no clarification questions. Opt automatic Overview
generation into question-free mode: use scoped context and safe defaults, prefer
bounded preliminary text review for symptom investigations, and show limitations.
When essential information cannot be resolved, create a visibly blocked draft
instead of asking a question or inventing executable authority. Such a draft must
fail canonical validation/approval, even if a client attempts to remove blockers.
Retain authorization, exact-action review, query validation and historical records.
Remove the query clarification response form from the automatic workflow experience.
This does not add full-text query operators or certify a diagnosis from partial data.
