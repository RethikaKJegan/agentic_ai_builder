# Simpson Phase 3: durable read-only agentic investigations

## Why
Phase 2 resolves individual questions to evidence. Business investigations require validated composition, branching, parallel analysis, resumable state and source-backed reports.

## What changes
Add a versioned investigation capability catalogue, bounded LLM graph planner, typed DAG validation, registered three-valued predicates, owner-scoped durable runs, parallel frontiers, input/resume/cancel operations, bounded CrewAI analytical tasks and shared-service CLI/API. Reuse Phase 1/2 knowledge/evidence, WorkflowStore, runtime graph scheduling primitives, lease heartbeat, CrewAdapter and BoundedLLM/OpenAIModelFactory. No frontend or company writes.

## Impact
Backend-only domain extension. Existing shared workflow/agent/tool contracts remain authoritative and unchanged. Investigation graphs are an explicitly versioned domain execution specification, not an alternative general-purpose workflow platform or unapproved production release.
