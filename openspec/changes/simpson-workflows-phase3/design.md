# Design

## Inspected existing components
BusinessRetrieval.preview/execute/inspect pin knowledge and exact mappings and authorize all source reads. Its evidence has records, findings, rules, missing facts, candidates and completeness, not the proposed interfaces in the prompt. BusinessSources checks current authority/source stamps. CrewAdapter builds real CrewAI Agent/Task/Crew objects with no tools, code or delegation and uses BoundedLLM. GraphRunner owns generic approved workflow execution with serialized next-node scheduling and lease heartbeat; its release/registry authority must not be bypassed or weakened. WorkflowStore supplies durable SQLite/PostgreSQL transactions.

## Extension boundary
Introduce a domain-specific, read-only investigation service with scoped plan/run tables, consuming Phase 2 request IDs and the existing CrewAdapter/model bridge. Extract a pure ready-frontier scheduler helper shared by GraphRunner and investigations; do not replace generic production release/approval paths. New graphs have an explicit schema and catalogue fingerprint. No client-defined executable capabilities or queries. Existing planner integration remains intact; new endpoints and CLI expose investigations without requiring a production workflow release.

## Planning
An LLM receives bounded saved ontology context, interpreted objective, task requirements, gaps and authorized capability schemas; strict JSON must pass deterministic graph validation. A deterministic offline planner is explicitly reported and useful for backend testing, never represented as model generation. The user can explicitly request model planning. Planner repair is at most one bounded attempt. Planning performs metadata reads only. Graphs persist knowledge/version/hash and source binding stamps. Required tasks and mappings cannot be dropped; unsupported operations reject planning.

## Execution and persistence
Backend owns typed DAG/control edges, registered predicates with true/false/unknown coverage, joins, branch skips, state transitions, budgets and owner scope. Persist each node intent before work and its validated result after work. A run-level expiring lease with heartbeat fences concurrent executors; independent ready nodes execute on a bounded thread pool. Expired deterministic/read intents can retry with stable Phase 2 request keys; interrupted model calls require explicit resume, consume reserved budget and never rerun completed nodes. No provider work under application transactions. Input assertions are labelled unverified and never become source facts or policy authority. Resume rechecks current authority, saved graph hash, pinned knowledge and source stamps before returning any output.

## Evidence and models
Agents receive allowlisted bounded mapped observations, source refs and gaps, never credentials, unrestricted tools or raw database access. Output schema requires valid source refs and distinguishes interpretations from facts; unsupported claims become unverified and cannot establish identity, diagnosis or approval. User objectives/source strings are untrusted. The report deterministically preserves all retrieved source facts/rule outcomes/gaps and separates optional model narrative. Structured evidence budget overflow fails explicitly rather than silently trimming required data. Actual CrewAI tests use a fixture provider; configured model/live-source evaluations are separate and recorded honestly.
