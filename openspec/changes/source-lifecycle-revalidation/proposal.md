# Generic source lifecycle revalidation

Preserve a connection's stable dataset and review identities when the same owned endpoint is reconnected. Match a verified, secret-free endpoint/principal fingerprint, never display names. Deletion remains a hard identity boundary. Hide unverified metadata from planning and joins while profiling or unavailable. Diagnose missing/disconnected/profiling sources before semantic scope checks. Existing published scopes still require regeneration after credentials or metadata revisions change; no writes, grants or approvals are migrated.
