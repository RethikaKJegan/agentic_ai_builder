# Subway autonomous investigations

Extend normal read-only Subway Overview investigations with run-owned adaptive
control. Reuse GraphRunner, canonical action plans, Registry grants, existing
OpenAI evaluation, CrewAI, scoped working memory and checkpoints. Business cases
and their lifecycle remain independent. Ordinary Phase 1 queries retain fixed DAGs.

Evaluate evidence before granting each action and before workflow completion.
Persist structured goal requirements, deterministic receipt checks, decisions,
waits, budgets and revision history in the existing run. Revisions may change only
unfinished read-only actions using capabilities and exact agent/tool authority
already approved for that run. Validate replacement DAGs and preserve completed
actions, outputs, approvals, correlations, checkpoints and cumulative usage.

Add an explicit investigation assessment contract without altering evaluator v1.
Expose adaptive progress and typed human input through existing run APIs/UI.
Unavailable source content, unsupported identities, unknown policy and unresolved
causality remain gaps. No deployment, external communication or Phase 3 triggers.
