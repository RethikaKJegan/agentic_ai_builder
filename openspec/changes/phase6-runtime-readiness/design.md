# Design

Add compatible GET query parameters with keyset cursors, workspace-scoped filters applied before LIMIT, and canonical collection envelopes. Existing canonical operation payloads remain unchanged. Event cursors use persisted sequence; run cursors use durable insertion order. UI uses serialized bounded polling, retains confirmed data on transient errors, stops selected terminal-run polling after draining events, and exposes explicit history paging. Server decides approval eligibility from exact gate roles, permission and workspace membership. Enforced governance remains read-only; editable policies remain explicitly browser-only drafts. Trigger reads omit credentials and provider references. Production activation keeps provider preparation, configuration validation and fresh Registry checks. No schema/data migration or external provider writes.
