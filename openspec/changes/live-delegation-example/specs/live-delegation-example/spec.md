## ADDED Requirements

### Requirement: Live read-only delegation evidence
The example runner SHALL execute real bounded model decisions and an authorized GitHub read, preserve independent master progress, and persist the combined result with tool and task handoffs.

#### Scenario: Repository claim needs checking during project update drafting
- **WHEN** the example runner receives project notes and a repository claim
- **THEN** a specialist requests GitHub records and interprets them while the master drafts its independent update
- **AND** the combined output matches the actual repository facts
- **AND** saved evidence distinguishes real calls from synchronization instrumentation

### Requirement: Isolated reproducible example
The example runner SHALL use isolated workflow storage and redact credentials from saved evidence.

#### Scenario: Example completes
- **WHEN** the read-only demonstration completes
- **THEN** existing published workflows, credentials and operator backend processes remain unchanged
