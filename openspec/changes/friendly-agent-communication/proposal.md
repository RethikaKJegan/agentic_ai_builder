# Understandable live agent communication diagram

Make the diagram the only communication view. Show agent roles, recorded spawned helpers, concise task descriptions and execution states directly on cards. Label task, result and information connections in everyday language, animate only currently active recorded work, and update the canvas as polling discovers agents and handoffs. Clicking any card or connection opens readable input, reason, result and status details, with identifiers and raw evidence behind a disclosure.

Use one shared diagram for ordinary workflows and complete project action histories. Derive all business labels from exact workflow definitions and events, preserve run/revision isolation, and distinguish configured relationships from recorded exchanges. Do not add domain-specific examples, model calls, provider actions or contract changes. Remove the step-by-step presentation.
