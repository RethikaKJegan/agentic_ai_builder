Replace the three graph navigation views with one KG. Preserve underlying schema
metadata and technical join validators. Add bounded structured semantic extraction
from current schema evidence, durable inference jobs, explicit inferred/ambiguous
statuses, reviewer confirmation with provenance and automatic invalidation.

fabricated examples. Planning retrieval consumes the same semantic revision,
concepts, predicates and actual configured tools before workflow generation.
