## ADDED Requirements

### Requirement: Viewport-first editor
The editor SHALL prioritize Design, Agent hierarchy and Execution with two compact header rows and a remaining-height workspace.

#### Scenario: Open editor at normal zoom
- **WHEN** an editor is opened at 100% browser zoom
- **THEN** the workspace occupies the remaining viewport without stacked instructional or outline panels
- **AND** plan and lifecycle details remain available through a secondary drawer
- **AND** existing workflow action authorization and execution semantics are preserved
