# No execution schedule means immediate work

Actual saved requests for investigation/email and service-hour reports used
one_time with an empty once recurrence, causing an unnecessary run-time question.
Distinguish a composed one-time workflow from a scheduled future occurrence.
Declare immediate execution as the default in model guidance and normalize an
otherwise empty once recurrence when the objective contains no scheduling cue.
Preserve explicit dates/times, repetition and necessary future-time questions.
Immediate work still requires existing review and external-action approvals.
