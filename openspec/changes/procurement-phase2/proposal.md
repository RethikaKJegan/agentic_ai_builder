# Native procurement quotations, Calendar and PO simulation
## Why
The existing coordinator ends after RFQ submission. Predefined-vendor projects need durable quotation collection, deadline milestones, deterministic comparisons and purchase-order progression.
## What Changes
- Add opt-in Phase 2 setup and a reviewed simulation purchasing limit.
- Read matched Gmail replies through registered tools and extract evidence-backed quotations with bounded agents.
- Persist comparisons, exact policy authority, awards and POs with existing lifecycle guards.
- Create quotation and PO delivery Calendar milestones; synchronize tracking rows.
- Continue using the existing UI and unified communication graph.
## Impact
No shared execution-contract changes. Existing Phase 1 projects remain unchanged. Automatic purchase commitments require explicit reviewed simulation policy; real purchase approvals remain required.
