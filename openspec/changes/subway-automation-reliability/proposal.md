# Subway automations and reliability

Connect normal Subway Overview requests to existing DurableAutomation,
TriggerScheduler, lifecycle dispatch queue, Registry and GraphRunner. Reuse the
run-owned adaptive controller for independent scheduled/event occurrences without
requiring business cases. Preserve all existing tenant and historical workflows.

Extend recurring consent to owned native Subway read capabilities without requiring
a Google connection. Keep existing selected-account credentials and side-effect
consent mandatory for external actions. Revalidate exact reviewed source/field/
relationship scope and execution-time reporting periods for every occurrence.

Extend existing subscriptions/providers with case-independent workflow events,
authenticated source adapters, scoped deduplication and occurrence dispatch.
Snapshots are not live feeds; no provider is advertised without actual server
configuration. Preserve source freshness limitations rather than manufacturing
current operational evidence. Extend existing controls, history and monitoring.

Canonical contract extensions are additive and recorded explicitly in this change;
existing request/record shapes retain their meaning. No new scheduler, broker,
agent framework, deployment, production credential changes or live external writes.
