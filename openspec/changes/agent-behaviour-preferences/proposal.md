# Agent behaviour and safety preferences UI
Add a compact Agent Behaviour & Safety section within existing Organization Policies. Three preset-button groups (Communication, Behaviour & Safety, Response Boundaries), eight labelled on/off switches, conditional language selection, Custom indication after manual edits, Apply preferences and an Execution limits reference linking to the existing Usage & Limits tab. Persist applied preferences through the existing browser store; keep unsaved changes component-local. Clearly identify browser preferences without claiming runtime enforcement. Do not alter agent instructions, backend policy, authority, execution or datasets.
