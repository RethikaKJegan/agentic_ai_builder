## ADDED Requirements

### Requirement: Whole-envelope discovery allocation
Overview SHALL allocate source-discovery field suggestions from the remaining
byte capacity of the complete routing context, including knowledge, resolved
inputs, tools and event sources. It SHALL retain existing total/component bounds
and preserve authorization, selected accounts and metadata coverage disclosures.

#### Scenario: Broad procurement and email request
- **WHEN** independently bounded metadata and retrieved knowledge exceed the combined allowance
- **THEN** routing bounds optional field suggestions to the actual remaining allowance
- **AND** the unchanged complete routing envelope reaches intent interpretation
- **AND** every authorized source descriptor and supported relationship remains available

#### Scenario: Earlier non-Subway behavior
- **WHEN** a request uses the existing generic routing path
- **THEN** its context, authority and execution semantics remain unchanged
