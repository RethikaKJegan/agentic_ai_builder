# Simpson knowledge foundation — Phase 1

Extend the five-layer Business Ontology in place with a backend-only, versioned knowledge package. Preserve existing IDs, historical definitions, graph bindings and rule handlers. No company writes, frontend changes, orchestration or natural-language retrieval are included.

The package adds source-backed inheritance and relationships, typed attribute/mapping metadata, conservative identity definitions, lifecycle/time models, structured configured rules and explicit dependencies. Definitions are stored inside immutable ontology snapshots; mutable authoring files are only read by explicit import. Backend inspection and bounded diagnostics expose coverage and uncertainty.
