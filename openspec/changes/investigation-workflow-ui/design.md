# Design

Existing Overview uses createWorkflow and the generic approved workflow builder. BusinessInvestigations has a separate versioned domain DAG, not a canonical editable production release. Render it faithfully with ReactFlow/dagre in the same Workflows area, using read-only nodes and real source state; do not convert it into a forged approved general workflow. Supported investigation prompts automatically route to the investigation planner; an explicit mode lets users choose automation or investigations. Existing automation stays available.

A durable owner-scoped job table wraps planning/execute/resume. WorkerSupervisor hosts the job worker alongside existing components; current authority is resolved at execution, claims fence late results, expired jobs fail explicitly without paid replay. Browser polls short jobs/run GETs, preserves workflow/run/job IDs in URL and recovers after refresh. Model progress is shown as actual queued/running status, never fake milestones. Run records contain node states and evidence; canceled runs prevent later dispatch and late output.

UI schema validation uses separate Zod adapters for the domain contract. Graph is generated from backend nodes/edges and a deterministic DAG layout, with three-valued condition labels, selected/skipped connections and accessible node list fallback. Reports distinguish observations, interpretations, configured readiness outcomes and missing evidence. Source references link to the retrieved records; optional evidence drawer shows concepts/relationships/rules/source groups with hashes/fields collapsed under technical details.

Deployment: confirm Nginx routes domain to this repository, prepare private full application backup/code/frontend rollback, verify no active work before service restart, build/test in isolated output, retain old static assets, restart only builder services, import Phase 1 package through explicit versioned service after compatible code is running. Preserve credentials, cookies, source IDs and existing workflows; verify authenticated public website without operational writes. Real model test scope remains the explicitly authorized A-2022-12-013 investigation.

Live acceptance exposed an invalid model citation, correctly rejected by existing validation. Give analysis an explicit catalog of legal record/mapping pairs and a request-specific output schema, keeping validation fail-closed and one call per node. Offer a new explicit run for nonretryable failures; resume only when the recorded attempt/error permits it. Never silently replay the rejected paid invocation or substitute uncited findings.
