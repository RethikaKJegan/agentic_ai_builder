# Design

Add an opt-in structured response format to the bounded model bridge, separate from existing control protocols. Investigation analysis opts in with its citation-constrained output schema. Account for transmitted schema in token reservations; keep local validation authoritative and reject invalid output. Persist only schema paths, never invalid values. Explicit negative goal clauses are removed before task keyword detection, preserving positive clauses. No model-call retries or fabricated reports.

Deployment must preserve configuration, original run history and knowledge versions. Saved plans whose catalogue fingerprint changed require regeneration; explain this in retest instructions.
