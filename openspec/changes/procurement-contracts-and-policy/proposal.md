## Why
The live connector pilot validated provider operations but used session scripts and a JSON ledger. Reusable automation needs explicit domain records, evidence guards and approval rules before adding workers or new tools.

## What Changes
Define extension-owned versioned procurement record schemas, examples, state transitions, stop conditions and a reviewed default approval policy. Add an offline contract verifier. These domain records supplement unchanged canonical workflow/agent/tool contracts.

## Impact
Only new extension procurement files and this planning change. No runtime wiring, services, credentials, source-sheet writes, messages, Calendar operations or shared-contract changes. Spreadsheet creation, SQLite persistence and agent automation remain later steps.
