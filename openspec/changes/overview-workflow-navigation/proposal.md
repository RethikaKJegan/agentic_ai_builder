# Open generated workflows in Workflows

Overview currently navigates only read-only Overview intents. One-time delivery
and recurring requests render the entire review below the prompt. Navigate every
successfully prepared composition to the existing Workflows detail route, carrying
its durable Overview request key. Load the scoped review there to retain schedule,
approval, execution and report controls through refresh. Keep clarification,
failure and pending-generation feedback at the prompt. Returning to Overview may
show an open-workflow link but must not force navigation to an old completed request.
