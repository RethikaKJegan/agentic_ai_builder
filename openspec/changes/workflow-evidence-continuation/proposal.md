today/tomorrow against the server planning clock and explicit timezone, and allow
the selected account's primary calendar for an explicit “my calendar” request.

report using scoped ontology evidence and concrete limitations. Clearly defer the
unavailable original operations; do not claim the original request is complete,
invent records or metrics, or grant any external-action authority. Authorization,
malformed input, immutable historical drafts and provider failures remain enforced.
