# Knowledge graph retrieval before workflow creation

Rename the business graph UI to Knowledge graph. Add an owned, persistent metadata
search index and a bounded, explainable source preview before planning. Search
names, fields, saved descriptions, confirmed concepts and confirmed predicates;
expand only through executable declared/accepted relationships. The planner sees
at most four selected sources, current configured tools and their actual schemas.
The UI exposes ambiguity, indexing coverage and freshness. Agent references are
restricted to task source IDs within the generated workflow scope.

Existing query validation, current authority, write policies, approval gates and
legacy API names remain compatible. No business rows enter the search index.
Praxi is untouched. Search is deterministic lexical retrieval, not an embedding
service; absent descriptions or relationships remain explicit limitations.
