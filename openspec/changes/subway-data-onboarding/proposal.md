# Subway archive analysis and evidence-backed onboarding

Inspect the supplied central and finance archives directly in the existing
workspace, verify contents and extract schema evidence before integration. Follow
the Simpsons methodology: source provenance, observed schema/types, relationship
evidence, layered concepts and explicit unresolved business meaning. Never copy
Simpsons definitions, rules or data into Subway or infer policy from field names.

Preserve both live client logins and existing Simpsons workflows. Changes use the
dedicated Subway store, existing source/ontology interfaces and tenant boundary.
Do not send archive content to external models without explicit authorization.
Check available disk before restoration; bounded streaming inspection is permitted
without expanding company data across the nearly full server filesystem.
