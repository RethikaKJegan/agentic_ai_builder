# Design

Use the actual current Mesh lifecycle controls. Isolate npm ci/build/Next and browser API database from the running site. Pin installation to existing lockfile; run all browser specs by default with one worker and explicitly offline provider fixtures. Keep mocked visual-only suites clearly labeled, and add a real API release journey covering edits, graph changes, revision save/reload, validation, explicit approvals/publication/activation, execution, events, controlled failure, and no duplicate effects. Preserve canonical contract and negative security assertions. Inventory every required check with passed/failed/unexecuted/deferred evidence. Production smoke remains read-only while public identity is deferred. No automatic credential change, production workflow execution, or schema migration.
