# Design

Versioned contracts register existing business retrieval, deterministic coverage and model interpretation operations. External contracts are admitted only for known operation semantics with actual registered tools, connectors and schemas. A selection from the existing workflow planner provider is constrained to those contracts; offline diagnostic planning uses Phase 1 outcomes or explicit operation IDs, never a new domain keyword interpreter.

Prepared task DAGs and temporary agent definitions are scoped, hashed and persisted. Registry validates definitions and exact assignments. Each child is bound to one prepared task. Existing delegation enforces dependency order, injects only task context and actual dependency results, checks tool inputs/effects and validates returned evidence. Missing/unsupported inputs produce explicit non-executable composition states. The normal workflow lifecycle and existing CrewAI/runtime own execution.
