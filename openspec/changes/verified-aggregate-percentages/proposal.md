# Deterministic percentages from complete, compatible query counts

The spreadsheet/report workflow retrieved complete filtered and unfiltered counts
but omitted the requested percentage because report generation disallowed arithmetic.
Provide deterministic Decimal percentage evidence at the content boundary from direct
completed verified query dependencies. Require the same scope, metadata revision,
base dataset, no joins/grouping, exact count(*) and complete aggregate results. A
numerator must add filters to a denominator's filters. Zero totals and incompatible
or incomplete evidence must not yield a percentage. Preserve source references and
population limitations, and leave displayed-row arithmetic forbidden.
