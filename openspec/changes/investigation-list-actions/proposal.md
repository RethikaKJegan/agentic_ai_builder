# Investigation list actions

Add a three-dot menu with persistent rename and confirmed delete to business investigations. Names and deletion markers are owner-scoped presentation metadata, separate from immutable plans and source evidence. Delete removes the workflow from the list and disables new access/execution while retaining audit history. Reject deletion during active work. Reuse workflow.edit/delete permissions and existing UI components. Deploy after tests; do not rename/delete existing user workflows during acceptance.
