# Design

The Next.js origin owns the website gate; FastAPI stays private and retains its existing shared identity and permission/session system. Next proxy checks every /app and /api/backend request, except signed webhook ingress and the Google callback whose existing backend verification remains authoritative. Direct backend session bootstrap is gated too. Login/logout routes validate exact configured origins. Password hash and random HMAC secret live in ignored frontend/.env.local. Authentication does not confer new execution permissions or reconnect tools. Logout clears the gate and backend browser cookies, preserving workspace data and browser drafts. Persistent secret keeps website sessions valid across process restarts; expiry is eight hours. Login attempt budget is process-local, appropriate for the current single-instance deployment.
