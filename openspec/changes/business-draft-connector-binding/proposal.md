# Match Google action effects after standalone workflow binding

The saved Gmail-only investigation is unsupported solely because the business
composer compares its draft side effect to the unbound deployment connector.
Procurement automatic mode marks that shared connector read-like, while its
standalone workflow binding correctly restores external-write approval semantics.
Planning therefore rejects the very action whose runtime binding is protected.

Expose a trusted connector effect classification for a given workflow context and
share its standalone-action rule with runtime binding. Business compositions use
the standalone context when matching, retaining destination, schema, credential,
permission and approval checks. Do not enable multiple actions, web research,
automatic email sending or change the user's saved failed investigation.
