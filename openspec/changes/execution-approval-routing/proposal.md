# Keep execution approval separate from missing planning information

The saved black-smoke request was blocked solely because the intent model put a
normal email approval notice into missing_requirements. Distinguish unambiguous
execution-approval notices from unresolved business inputs. Apply this consistently
to composed email, Sheets, Calendar and web-search workflows. Preserve all connector,
capability, recipient, resource, permission and runtime approval checks.

Use explicit server-owned planning instructions and conservative normalization of
approval-only notices. Ambiguous notices, actual access gaps, missing inputs and
mixed approval/input statements remain unresolved. No provider action is authorized
by normalization, and existing blocked requests retain their historical result.
