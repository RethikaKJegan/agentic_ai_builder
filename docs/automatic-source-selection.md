# Automatic source selection

Overview accepts one requirement prompt. No input-source mode selector is shown. The planner infers known setup values and event mappings; existing manually configured workflows remain supported by canonical APIs and their existing run-input forms.

For authenticated users with workspace read permission (`workflow.view`), the backend supplies current saved knowledge and source references from published workspace revisions. Client-provided workspace evidence is replaced by the server snapshot. Reads are bounded to 20 knowledge documents and 20 published revisions; knowledge is capped at 48,000 serialized characters, with each text field capped at 12,000 characters. Disabled, pending, failed, archived, malformed and secret-bearing knowledge records are excluded. Supported knowledge fields include title/name/description/summary/content/text and source URL/Sheets identifiers/ranges. URL-only records are explicitly marked as not having ingested content. Knowledge ingestion remains outside this change.

The live planner inspects up to eight unique supported spreadsheet references, putting links in the user's prompt first and adding existing saved references. Provider access is checked through the existing read-only discovery adapter. Inaccessible optional saved references are reported to the model; inaccessible explicit prompt links retain their safe setup error. The AI selects relevant candidates and must retain specific unresolved requirements for ambiguity, missing access, unsupported tools or absent content. A connected account alone does not supply a resource identifier or prove access to every resource. No arbitrary URL downloader or new connector is introduced.

At execution, accepted agents with `data.read` receive current bounded knowledge from their Registry-owned workspace as separate untrusted task data. Agent input schemas, registered instructions, limits, grants and release authorization remain unchanged. This covers ordinary model calls, master decisions and delegated agent/tool decisions. Additional supported sources still use authorized read tools for fresh external facts; external rows are not frozen as knowledge constants. References do not grant connector permissions.

Verification and exact existing-file review patches are in `openspec/changes/automatic-source-selection/`; private run logs, build identity, source hashes and prepared rollback are under `.local/automatic-source-selection/`. No production planning/execution, provider probe, email or Sheets write is required for live verification. Google Workspace production authentication remains deferred as previously requested.
